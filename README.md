# omarchy-rices

[🇷🇺 Русский](README.ru.md)

Omarchy themes of eleven rices, plus a **dynamic theme from the wallpaper** for each of them. The Customizer's
**Rices** tab applies the rices' variants, and its **Dynamic** tab sets up the dynamic theme.

| **Glyph** | Glyph dark / light (+ mono) | [glyph-rice](https://github.com/Nebelung-cloud/glyph-rice) (GPL-3.0) |
| Nothing (same generator, `nothing/`) | Signal, CMF, Ash, Ember, Steel (+ mono), Ash Light (+ mono), Glyph White | own |

| **Bruteon** | Light, Dark (+ colour) | [Darkkal44/Bruteon](https://github.com/Darkkal44/Bruteon) (GPL-3.0) |
| **Cozytile** | Cozy, Sakura, Natura, Everforest, Carbon (+ colour) | [Darkkal44/Cozytile](https://github.com/Darkkal44/Cozytile) (look only) |
| **Rumda** | Dark, Light (+ colour) | [hexonide/rumda](https://github.com/hexonide/rumda) (look only) |

The palettes and forms are re-made here, and every theme is generated by its rice's `build.py` on top of
`nothing/build.py`. The rices' original wallpapers are **not** in the repository: `install.sh` downloads them from the
source repos, and they stay under their authors' terms (see [NOTICE](NOTICE)).

## Install

With the Customizer: `bash install.sh` of [omarchy-customizer](https://github.com/KamradSmeshnyavy/omarchy-customizer)
offers `rices` as a companion. By hand:

```sh
sudo pacman -S --needed python-pillow python-numpy ffmpeg
git clone https://github.com/KamradSmeshnyavy/omarchy-rices ~/.local/share/omarchy-rices
bash ~/.local/share/omarchy-rices/install.sh      # --no-build: links only; --list: theme names
```

The script builds the themes, links them as `~/.config/omarchy/themes/<rice>-<variant>`, and links
`~/.local/bin/omarchy-rice-dynamic`. It does not touch a path that exists and is not a link. For the theme to recolour
itself on wallpaper change you need the wallpaper plugin
[omarchy-wallpaper-fx](https://github.com/KamradSmeshnyavy/omarchy-wallpaper-fx); without it, rebuild by hand.

## Dynamic theme

`omarchy-rice-dynamic` writes `~/.config/omarchy/themes/dynamic-<rice>` (or `dynamic` without a rice) from the
wallpaper and applies it.

```sh
omarchy-rice-dynamic build vitreus [IMAGE]           # one-off build (no settings saved)
omarchy-rice-dynamic set vitreus --scheme accent --look Liquid-Retro --mode dark   # remember and rebuild
omarchy-rice-dynamic build plain                     # the theme "dynamic" from any wallpaper, no rice
omarchy-rice-dynamic add vitreus PICTURE… --local    # into ~/.config/omarchy/backgrounds/dynamic-vitreus/
omarchy-rice-dynamic wallhaven search vitreus "liquid abstract"   # SFW thumbnails into the cache
omarchy-rice-dynamic wallhaven get vitreus ID…        # download the picks into the pool
omarchy-rice-dynamic list [RICE]                      # rices and settings, or the rice's wallpapers
```

- **Colours** are read by [Iris](https://github.com/Harman1307/iris) (`scripts/iris_colors.py`), which is what Vitreus
  uses for Glass. It takes the background, panels, text, the accent and red / green / yellow from the picture's real
  colours. A video or GIF gives its colours through a representative frame (ffmpeg), and the wallpaper stays live.
- **Modes** (`--scheme`, in `nothing/dynamic_map.py`):

  | Mode | What it does |
  |---|---|
  | `vitreus` | exactly Vitreus's eleven colours |
  | `wallpaper` / `soft` / `vivid` | the wallpaper read the Vitreus way, as is / quieter / brighter |
  | `pure` / `pure-soft` / `pure-vivid` | the same, but the terminal and code use only hues that are on the picture |
  | `mono` | one hue of the wallpaper |
  | `grey` | Vitreus's greys |
  | `accent` | the look's variant palette with only the accent from the wallpaper |

- **Look** (`--look`, a Customizer preset): the variant whose form the theme wears. Retro in the wallpaper's colours
  is still Retro.
- **Light / dark** (`--mode`): `auto` follows the wallpaper. In `accent`, the opposite mode turns the variant's palette
  over (OKLab: the same hues, with the backgrounds and the ink swapped in lightness).
- **Engines**: `rice` puts the colours into the rice's own palette, and its `build.py` (`dynamic()`) builds every app
  theme in the rice's character. `colors` writes only `colors.toml`, and Omarchy templates do the rest. DOT-MATRIX and
  `plain` use `colors`.
- **Pool** of the rice's wallpapers: `<rice>/wallpapers/`, the `backgrounds/` of every variant, and your own in
  `~/.config/omarchy/backgrounds/dynamic-<rice>/`.
- **Recolouring**: the wallpaper plugin calls `omarchy-rice-dynamic on-wallpaper` on every change. One worker runs,
  the last request wins, and the log is in `$XDG_RUNTIME_DIR/omarchy-rice-dynamic.log`.
- **Settings**: `~/.config/omarchy/dynamic.json`. The Customizer finds the presets through
  `$OMARCHY_CUSTOMIZER_DIR` or `~/.config/omarchy/plugins/kamradsmeshnyavy.customizer`.

## Layout

`<rice>/build.py` holds the palettes and generates `<rice>/<variant>/`. `nothing/` is the shared generator (terminals,
nvim, helix, btop, VS Code, TUI apps) plus the Glyph palettes, and `nothing/efter/` holds templates from
catppuccin-mocha-efter. `originals.py` fetches the rices' original wallpapers. `scripts/` holds
`omarchy-rice-dynamic`, `wallpaper_colors.py` and Iris.
